# Rijopleiding Uden Website

Official website for **Rijopleiding Uden**, a driving school in Uden, Netherlands. The website provides information about services, contact details, photo gallery, and a smooth, interactive experience for visitors.

---

## 🌐 Live Demo

[View Live Website](https://rijopleidinguden.nl)


---

## ⚡ Features

- Fully **responsive design** for desktop, tablet, and mobile.
- **Smooth scrolling** and **sticky navigation**.
- Animated **hero sections** and **gallery auto-scroll**.
- Interactive **WhatsApp & social media links**.
- Scroll-to-top button and hover/active effects on navigation.
- Footer with **animated background** and wavy SVG overlay.

---

## 🛠️ Technologies Used

- **HTML5 & CSS3** – Semantic markup and modern styling.
- **JavaScript (ES6+)** – DOM manipulation, animations, AJAX.
- **Remix Icon & FontAwesome** – Icons for social links and contact.
- **TailwindCSS** – Utility-first responsive design.
